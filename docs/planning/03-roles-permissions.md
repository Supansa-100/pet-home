# 03 — บทบาทและสิทธิ์การใช้งาน (User Roles & Permissions)

> **โปรเจกต์:** PET-HOME — แพลตฟอร์มสื่อกลางหาบ้านให้สัตว์เลี้ยง
> **เอกสาร:** Step 1.3 | Phase 1 — Planning Only
> **อ้างอิงจาก:** `01-system-overview.md`, `02-requirements.md`

จากการวิเคราะห์ Requirement ของระบบ PET-HOME เพื่อให้การควบคุมสิทธิ์การเข้าถึงข้อมูลและการใช้งานแพลตฟอร์มเป็นไปอย่างถูกต้อง
และปลอดภัย จึงได้มีการออกแบบบทบาท (Roles) และสิทธิ์ (Permissions) ดังนี้

---

## 1. ข้อเสนอแนะบทบาทเพิ่มเติม (Additional Role Suggestion)

นอกเหนือจาก 3 บทบาทหลักที่กำหนดมา (Admin, ผู้อุปการะ, เจ้าของสัตว์เลี้ยง) ขอเสนอให้เพิ่มบทบาท **"Guest (ผู้เยี่ยมชมทั่วไป / ยังไม่เข้าสู่ระบบ)"**

**เหตุผลที่ต้องมีบทบาท Guest:**
1. **การดึงดูดผู้ใช้งาน (User Acquisition):** แพลตฟอร์มสื่อกลางจำเป็นต้องให้บุคคลภายนอกสามารถเข้ามาดูประกาศ ค้นหา และเห็นภาพรวมของสัตว์เลี้ยงได้ก่อน เพื่อสร้างความสนใจก่อนที่จะบังคับให้สมัครสมาชิก
2. **การรักษาความปลอดภัย (Security Context):** การกำหนดขอบเขตของ "ผู้ที่ยังไม่ล็อกอิน" ให้ชัดเจน ว่าทำอะไรได้และทำอะไรไม่ได้ (เช่น ห้ามดูเบอร์โทร, ห้ามส่งคำขอ, เข้าหน้าแชทไม่ได้) จะช่วยให้การเขียนโค้ดเพื่อทำ Route Protection (Middleware) รัดกุมยิ่งขึ้น

## 2. ตารางสรุปบทบาทและสิทธิ์การใช้งาน (Roles & Permissions Matrix)

| Role | คำอธิบายบทบาท | สิทธิ์ที่ทำได้ (Actions) | หน้าจอที่เข้าถึงได้ (Accessible Pages) | ข้อมูลที่มองเห็นได้ (Visible Data) | ข้อจำกัดของ Role |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. Guest**<br>*(ผู้เยี่ยมชมทั่วไป)* | ผู้ใช้งานที่เข้ามาเยี่ยมชมเว็บไซต์ แต่ยังไม่ได้สมัครสมาชิกหรือยังไม่ล็อกอิน | - ค้นหาสัตว์เลี้ยงด้วย Keyword<br>- กรองข้อมูลประกาศ<br>- อ่านรายละเอียดประกาศ<br>- สมัครสมาชิก / เข้าสู่ระบบ | - หน้าแรก (Home)<br>- หน้าค้นหาและรายการประกาศ (Feed)<br>- หน้ารายละเอียดสัตว์เลี้ยง<br>- หน้า Login / Register | - รูปภาพและรายละเอียดสัตว์เลี้ยงทั่วไป<br>- สถานะของประกาศ (Available / Pending) | - ไม่สามารถดูข้อมูลติดต่อส่วนตัวของเจ้าของได้<br>- ไม่สามารถส่งคำขออุปการะได้<br>- ไม่สามารถเข้าถึงระบบแชทได้ |
| **2. Adopter**<br>*(ผู้อุปการะ)* | สมาชิกในระบบที่กำลังมองหาสัตว์เลี้ยงเพื่อนำไปดูแล | - **สิทธิ์ทั้งหมดของ Guest**<br>- ส่งคำขอรับอุปการะพร้อมแนบข้อความแนะนำตัว<br>- ส่งและรับข้อความแชทกับเจ้าของสัตว์<br>- ติดตามสถานะคำขอของตนเอง<br>- ยกเลิกคำขอที่ยังรอพิจารณา<br>- จัดการข้อมูลโปรไฟล์ส่วนตัว | - **สิทธิ์หน้าจอทั้งหมดของ Guest**<br>- หน้า Profile ของตนเอง<br>- หน้ารายการคำขอของฉัน (My Requests)<br>- หน้าต่างแชท (Chat Room) | - ข้อมูลสัตว์เลี้ยงทั้งหมด<br>- ข้อมูลโปรไฟล์เบื้องต้นของเจ้าของสัตว์<br>- สถานะคำขออุปการะของตนเอง<br>- ประวัติการแชทของตนเอง | - ดูและแชทได้เฉพาะห้องสนทนาที่เกิดจากคำขอของตนเองเท่านั้น<br>- ไม่สามารถแก้ไขหรือยุ่งเกี่ยวกับข้อมูลของผู้อื่นได้ |
| **3. Pet Owner**<br>*(เจ้าของสัตว์เลี้ยง)* | สมาชิกในระบบที่ต้องการหาบ้านให้สัตว์ เป็นผู้ตั้งประกาศและคัดกรองผู้อุปการะ | - **สิทธิ์ทั้งหมดของ Guest**<br>- สร้าง แก้ไข และปิดประกาศสัตว์เลี้ยงของตนเอง<br>- ดูรายการคำขอที่ส่งมายังประกาศของตน<br>- อนุมัติ (Approve) หรือ ปฏิเสธ (Reject) คำขอ<br>- ส่งและรับข้อความแชทตอบกลับ Adopter<br>- จัดการข้อมูลโปรไฟล์ส่วนตัว | - **สิทธิ์หน้าจอทั้งหมดของ Guest**<br>- หน้า Profile ของตนเอง<br>- หน้าจัดการประกาศของฉัน (My Listings)<br>- หน้ารายการคำขอที่ส่งเข้ามาพิจารณา<br>- หน้าต่างแชท (Chat Room) | - รายละเอียดประกาศของตนเองทั้งหมด<br>- รายการคำขอที่ถูกส่งมาที่ประกาศของตน<br>- ข้อมูลแนะนำตัวและโปรไฟล์เบื้องต้นของ Adopter ที่ส่งคำขอมา<br>- ประวัติการแชทในแต่ละคำขอ | - ไม่มีสิทธิ์ยุ่งเกี่ยวกับประกาศของสมาชิกคนอื่น<br>- เมื่อประกาศเปลี่ยนสถานะเป็น Adopted แล้ว อาจถูกจำกัดไม่ให้แก้ไขข้อมูลประกาศบางส่วน |
| **4. Admin**<br>*(ผู้ดูแลระบบ)* | ผู้ดูแลสูงสุดของแพลตฟอร์ม มีหน้าที่ควบคุมความปลอดภัย จัดการเนื้อหาและผู้ใช้ | - เข้าสู่ระบบในฐานะแอดมิน<br>- ดูสถิติภาพรวมของระบบ<br>- ระงับ (Ban) หรือ ปลดแบน ผู้ใช้งาน<br>- ตรวจสอบ ซ่อน หรือลบประกาศที่ไม่เหมาะสม<br>- เพิ่ม ลบ แก้ไข หมวดหมู่สัตว์เลี้ยง | - หน้า Admin Dashboard<br>- หน้าจัดการผู้ใช้งาน (User Management)<br>- หน้าจัดการประกาศทั้งหมด (Listing Management)<br>- หน้าจัดการหมวดหมู่ (Category Management) | - ข้อมูลสถิติของระบบทั้งหมด<br>- ข้อมูลโปรไฟล์ของผู้ใช้งานทั้งหมดในระบบ<br>- ประกาศทั้งหมดในระบบ (ทั้งสถานะปกติและถูกซ่อน)<br>- *(ข้อเสนอแนะ: ไม่ควรให้สิทธิ์อ่านข้อความแชทส่วนตัวของผู้ใช้ เว้นแต่มีการกด Report เข้ามา)* | - ไม่ควรใช้บัญชี Admin ในการสร้างประกาศหาบ้านหรือส่งคำขออุปการะ (ควรแยกบัญชีใช้งานส่วนตัวออกจากบัญชี Admin) |

## 3. เงื่อนไขและข้อสังเกตเพิ่มเติม (Implementation Notes)

1. **บทบาทที่ทับซ้อนกัน (Overlapping Roles):** ในทางปฏิบัติ บัญชีผู้ใช้ 1 บัญชี (User Account) สามารถเป็นได้ทั้ง **Adopter** และ **Pet Owner** ในตัวเดียวกัน ระบบไม่ควรบังคับให้ผู้ใช้ต้องสมัคร 2 ไอดีแยกกัน การแบ่งบทบาทในตารางด้านบน เป็นการแบ่งตาม **"บริบทของการใช้งาน ณ ขณะนั้น (Contextual Role)"** 
   - เช่น วันนี้ User A ลงโพสต์หาบ้านให้แมว (บริบทเป็น Pet Owner)
   - วันต่อมา User A ไปกดขอรับอุปการะสุนัขจากโพสต์ของ User B (บริบทเป็น Adopter)
   - *เว้นแต่บทบาท Admin ที่ควรผูกกับบัญชีเฉพาะและแยกฟังก์ชันออกไปชัดเจน*
2. **Data Privacy (ความปลอดภัยของข้อมูล):** ข้อมูลที่มีความละเอียดอ่อน (เช่น เบอร์โทรศัพท์, ที่อยู่แบบละเอียด) ไม่ควรให้ Guest และ Adopter ทั่วไปเห็นในหน้าแรก ควรให้ตกลงแลกเปลี่ยนกันเองในระบบแชทเท่านั้น เพื่อป้องกันมิจฉาชีพดึงข้อมูลไปใช้
