# Frontend Page Structure - PET-HOME

เอกสารนี้ระบุโครงสร้างหน้าจอ Frontend สำหรับระบบ PET-HOME (สร้างด้วย React + Vite, MUI, React Router) โดยอิงตาม API Contract และ Requirement เพื่อให้เห็นภาพรวมของ User Interface และประสบการณ์ผู้ใช้ (UX) ก่อนลงมือเขียนโค้ด

---

## 1. Layouts หลักของระบบ

ระบบจะใช้ Layout หลัก 3 รูปแบบ เพื่อรองรับกลุ่มผู้ใช้และบริบทหน้าที่ต่างกัน

1.  **Public Layout (สำหรับผู้ใช้ทั่วไป / ผู้ที่ยังไม่ได้ล็อกอิน)**
    *   **Topbar:** โลโก้, ช่องค้นหา, เมนูหลัก (หน้าแรก, ดูสัตว์เลี้ยง), ปุ่มเข้าสู่ระบบ / สมัครสมาชิก
    *   **Footer:** ข้อมูลการติดต่อ, ลิงก์นโยบาย

2.  **User Layout (สำหรับ Pet Owner และ Adopter)**
    *   **Topbar:** โลโก้, แจ้งเตือน (Bell Icon), รูปโปรไฟล์ (Dropdown Menu: โปรไฟล์, ออกจากระบบ)
    *   **Sidebar (ยุบได้บนมือถือ):** หน้าแรก, ประกาศของฉัน (Owner), คำขอของฉัน (Adopter), กล่องข้อความแชท, ตั้งค่าโปรไฟล์

3.  **Admin Layout (สำหรับผู้ดูแลระบบ)**
    *   **Topbar:** โลโก้ (Admin Mode), แจ้งเตือน, โปรไฟล์แอดมิน
    *   **Sidebar (แบบถาวรบน Desktop):** แดชบอร์ดภาพรวม, จัดการผู้ใช้, จัดการประกาศหาบ้าน, จัดการหมวดหมู่, จัดการเนื้อหาไม่เหมาะสม (Reports), บันทึกระบบ (Audit Logs)

## 2. โครงสร้างหน้าจอแยกตามกลุ่มผู้ใช้งาน

### 2.1 ผู้ใช้ทั่วไป (Guest / Public)

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **หน้าแรก (Home Page)** |
| **URL Path** | `/` |
| **ข้อมูลที่แสดง** | แบนเนอร์หลัก, ปุ่ม Call to action (หาบ้านให้สัตว์ / หาเพื่อนคู่ใจ), รายการสัตว์เลี้ยงมาใหม่ (Cards) |
| **Action สำคัญ** | กดดูรายละเอียดสัตว์เลี้ยง, ค้นหา |
| **เชื่อมโยง API** | `GET /api/v1/pets` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **รายการสัตว์เลี้ยงหาบ้าน (Pets Feed)** |
| **URL Path** | `/pets` |
| **ข้อมูลที่แสดง** | รายการสัตว์เลี้ยงในรูปแบบ Grid/Card, เครื่องมือตัวกรอง (ชนิด, พันธุ์, พื้นที่, อายุ) |
| **ฟอร์ม / ตาราง** | ฟอร์มค้นหาและตัวกรอง (Filter Form) |
| **เชื่อมโยง API** | `GET /api/v1/pets`, `GET /api/v1/categories`, `GET /api/v1/master/provinces` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **รายละเอียดสัตว์เลี้ยง (Pet Details)** |
| **URL Path** | `/pets/:id` |
| **ข้อมูลที่แสดง** | รูปภาพสัตว์เลี้ยง (Carousel), ข้อมูลสัตว์, เงื่อนไขการรับเลี้ยง, ข้อมูลเจ้าของแบบย่อ |
| **Action สำคัญ** | ปุ่ม "ขอรับอุปการะ" (บังคับ Login), ปุ่ม "แชร์", ปุ่ม "รายงานความไม่เหมาะสม" |
| **เชื่อมโยง API** | `GET /api/v1/pets/:id` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **เข้าสู่ระบบ และ สมัครสมาชิก (Auth Pages)** |
| **URL Path** | `/login`, `/register`, `/forgot-password` |
| **ฟอร์ม / ตาราง** | ฟอร์ม Login (Email, Password), ฟอร์ม Register (ชื่อ, อีเมล, รหัสผ่าน, เลือก Role) |
| **เชื่อมโยง API** | `POST /api/v1/auth/login`, `POST /api/v1/auth/register` |

### 2.2 ผู้อุปการะ (Adopter)
*สืบทอดสิทธิ์เข้าถึงหน้าของ ผู้ใช้ทั่วไป ทั้งหมด*

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **ส่งคำขอรับอุปการะ (Adoption Request Form)** |
| **URL Path** | `/pets/:id/request` (เป็นหน้าย่อย หรือ Dialog Popup) |
| **ฟอร์ม / ตาราง** | ฟอร์มกรอกข้อความแนะนำตัว, อัปโหลดรูปภาพสภาพแวดล้อมบ้าน |
| **Action สำคัญ** | ปุ่ม "ส่งคำขอ" |
| **เชื่อมโยง API** | `POST /api/v1/requests`, `POST /api/v1/upload` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **แดชบอร์ดคำขอของฉัน (My Requests)** |
| **URL Path** | `/user/requests` |
| **ข้อมูลที่แสดง** | รายการคำขอที่ตนเองส่งไป พร้อมสถานะ (รอพิจารณา, อนุมัติ, ปฏิเสธ) |
| **Action สำคัญ** | คลิกเพื่อดูรายละเอียด/ประวัติแชทกับเจ้าของ |
| **เชื่อมโยง API** | `GET /api/v1/requests/my-requests` |

---

### 2.3 เจ้าของสัตว์เลี้ยง (Pet Owner / Poster)
*สืบทอดสิทธิ์เข้าถึงหน้าของ ผู้ใช้ทั่วไป ทั้งหมด*

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **จัดการประกาศของฉัน (My Posts / Dashboard)** |
| **URL Path** | `/owner/pets` |
| **ข้อมูลที่แสดง** | ตารางหรือรายการประกาศทั้งหมดที่ตัวเองสร้าง พร้อมจำนวนคำขอที่ได้รับ และสถานะของสัตว์เลี้ยง |
| **Action สำคัญ** | ปุ่ม "สร้างประกาศใหม่", ปุ่ม "แก้ไข", ปุ่ม "ปิดประกาศ" |
| **เชื่อมโยง API** | `GET /api/v1/pets?ownerId=me`, `PUT /api/v1/pets/:id/status` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **ฟอร์มสร้าง/แก้ไขประกาศ (Create/Edit Pet Listing)** |
| **URL Path** | `/owner/pets/create`, `/owner/pets/edit/:id` |
| **ฟอร์ม / ตาราง** | ฟอร์มข้อมูลสัตว์เลี้ยง (ชื่อ, สายพันธุ์, เพศ, อัปโหลดรูปภาพหลายรูป, ข้อความอธิบาย) |
| **Action สำคัญ** | ปุ่ม "บันทึกและโพสต์" |
| **เชื่อมโยง API** | `POST /api/v1/pets`, `PUT /api/v1/pets/:id`, `POST /api/v1/upload` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **จัดการคำขอรับอุปการะ (Adoption Requests Management)** |
| **URL Path** | `/owner/pets/:id/requests` |
| **ข้อมูลที่แสดง** | รายชื่อผู้อุปการะที่ส่งคำขอเข้ามาของสัตว์เลี้ยงตัวนั้นๆ (โปรไฟล์, ข้อความ, รูปภาพบ้าน) |
| **Action สำคัญ** | ปุ่ม "อนุมัติ" (Approve), ปุ่ม "ปฏิเสธ" (Reject), ปุ่ม "แชทพูดคุย" |
| **เชื่อมโยง API** | `GET /api/v1/requests/received?petId=...`, `PUT /api/v1/requests/:id/status` |

### 2.4 ฟีเจอร์ที่ใช้งานร่วมกัน (Adopter & Pet Owner)

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **ระบบพูดคุย (Chat System)** |
| **URL Path** | `/chat`, `/chat/:roomId` |
| **ข้อมูลที่แสดง** | รายชื่อห้องแชทฝั่งซ้าย (Sidebar) และ หน้าต่างสนทนาฝั่งขวา |
| **Action สำคัญ** | พิมพ์ข้อความ, ส่งรูปภาพ, อัปเดตสถานะแบบ Real-time |
| **เชื่อมโยง API** | `GET /api/v1/chats`, `GET /api/v1/chats/:id/messages`, `POST /api/v1/chats/:id/messages` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **ตั้งค่าโปรไฟล์ (Profile Settings)** |
| **URL Path** | `/settings/profile` |
| **ฟอร์ม / ตาราง** | ฟอร์มแก้ไขรูปอวตาร, ชื่อ, เบอร์โทรศัพท์, ที่อยู่ |
| **Action สำคัญ** | ปุ่ม "บันทึกการเปลี่ยนแปลง" |
| **เชื่อมโยง API** | `GET /api/v1/users/profile`, `PUT /api/v1/users/profile` |

### 2.5 ผู้ดูแลระบบ (Admin)

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **แผงควบคุมหลัก (Admin Dashboard)** |
| **URL Path** | `/admin/dashboard` |
| **ข้อมูลที่แสดง** | Card สรุปจำนวนผู้ใช้, จำนวนโพสต์, อัตราความสำเร็จ และกราฟแสดงแนวโน้ม |
| **เชื่อมโยง API** | `GET /api/v1/dashboard/admin/summary` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **จัดการผู้ใช้งาน (Users Management)** |
| **URL Path** | `/admin/users` |
| **ข้อมูลที่แสดง** | ตาราง Data Grid รายชื่อผู้ใช้ (ชื่อ, อีเมล, บทบาท, สถานะ, วันที่สมัคร) |
| **Action สำคัญ** | ปุ่ม "เปิด/ปิดใช้งาน (Ban/Unban)", ฟิลเตอร์ค้นหาผู้ใช้ |
| **เชื่อมโยง API** | `GET /api/v1/users`, `PUT /api/v1/users/:id/status` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **จัดการหมวดหมู่ (Categories Management)** |
| **URL Path** | `/admin/categories` |
| **ฟอร์ม / ตาราง** | ตารางแสดงชนิดสัตว์/สายพันธุ์ และฟอร์ม Dialog สำหรับเพิ่ม/แก้ไขข้อมูล |
| **Action สำคัญ** | เพิ่มหมวดหมู่ใหม่, แก้ไข, ลบ |
| **เชื่อมโยง API** | `GET /api/v1/categories`, `POST /api/v1/categories`, `PUT /api/v1/categories/:id` |

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อหน้าจอ** | **ตรวจสอบประกาศและรายงาน (Moderation / Reports)** |
| **URL Path** | `/admin/reports` |
| **ข้อมูลที่แสดง** | ตารางแสดงรายงานจากผู้ใช้ (Post ที่ถูกรีพอร์ต, เหตุผล) |
| **Action สำคัญ** | ดูประกาศที่มีปัญหา, ปุ่ม "ลบ/ซ่อนประกาศ", ปุ่ม "เพิกเฉย (Ignore Report)" |
| **เชื่อมโยง API** | (Requires API additions for Reports module) |
